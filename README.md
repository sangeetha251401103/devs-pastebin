# DEVS PasteBin

A simple full-stack PasteBin application built using the MERN Stack.

## Features

- Create a paste
- View all saved pastes
- Delete a paste
- MongoDB database integration
- REST API with Express.js
- Responsive React frontend
- Deployed using Vercel and Render

## Tech Stack

### Frontend
- React
- Vite
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

```
devs-pastebin/
├── DEVS-backend/
└── devs-frontend/
```

## Installation

### Backend

```bash
cd DEVS-backend
npm install
npm start
```

### Frontend

```bash
cd devs-frontend
npm install
npm run dev
```
